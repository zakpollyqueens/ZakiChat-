Automatic upload

When enabled, due backups run when you open the app or return online.

This web scheduler cannot upload while the app is fully closed. Messages, contacts, profiles and other cloud-backed records normally sync after sign-in; this backup focuses on supported local preferences.

Included in backup

Supported appearance, language, chat preference, draft, wallpaper, keyboard, sound, notification preference and media-download settings. Authentication tokens, passwords, session secrets and unrelated browser data are excluded.
