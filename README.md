# Zamivox

Zamivox is a modern messaging platform by Zakmolanitech Solutions.

## Public entry points

- Website homepage: `index.html`
- Android download page: `download.html`
- Official Android APK: [Latest release asset](https://github.com/zakpollyqueens/ZakiChat-/releases/latest/download/app-release.apk)
- Release notes and version history: [GitHub Releases](https://github.com/zakpollyqueens/ZakiChat-/releases)
- Support and issue reporting: [GitHub Issues](https://github.com/zakpollyqueens/ZakiChat-/issues)

## Search indexing

The homepage includes search metadata and SoftwareApplication structured data. `robots.txt` permits public crawling. Add a sitemap with absolute production URLs and configure Google Search Console after confirming the deployed website's canonical domain.

## Android distribution

Use the signed `app-release.apk` for public installs; `app-debug.apk` is intended for testing. Verify the latest release asset and Android signing/update compatibility before announcing a release.
