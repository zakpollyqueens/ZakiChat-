## Android distribution

Use the signed `app-release.apk` for public installs; `app-debug.apk` is intended for testing. Verify the latest release asset and Android signing/update compatibility before announcing a release.


## Molano AI Keyboard compatibility

Molan Chat accepts Android's currently selected system keyboard in its chat, search, support, and other text fields. To use the shared Molano AI Keyboard across Molan Chat, ZakiTech, Molan Business, Molano AI, and other apps, install the Molano AI Keyboard APK from the [Molano AI Keyboard releases](https://github.com/zakpollyqueens/molanoai/releases), open **Molano AI Keyboard**, then explicitly enable it and select it in Android's keyboard/input-method settings. Android requires the user to approve and select a third-party keyboard; apps cannot silently switch the system keyboard. You can switch back to your previous keyboard in Android settings at any time.
